# Team Upload System

## Overview
A unified web application that combines public tournament registration functionality with an integrated secure admin portal. The admin portal is accessible only to users with admin roles through protected routes within the same application. Public users can register teams without authentication, while admin access remains fully protected.

## Core Features

### Team Registration (Public - No Authentication Required)
- Registration form with the following fields:
  - Team name (required)
  - Team logo upload (image file)
  - Captain name (required)
  - Captain phone number (required)
  - Team members list with names and optional player IDs
- **Enhanced form validation with graceful error handling and fallback mechanisms to prevent registration failures**
- **Silent error suppression with automatic retry logic for transient failures**
- **Safe validation that allows registration completion even with minor data inconsistencies**
- Success confirmation after registration submission
- Registration status check: display banner message based on admin-controlled status ("Registration is currently closed", "Coming Soon", "Paused", or allow registration when "Open") instead of the form when not open
- Registration limit check: if maximum registrations reached, display banner message "Registrations are full" instead of the form
- Duplicate registration prevention: if user has already registered, display banner message "You already registered a team" instead of the form
- Dynamic status updates without page reloads
- Automatic Excel export generation triggered on successful registration
- **Auto-approval system: all team registrations automatically receive approved status upon successful submission**
- **Automatic Team ID assignment: each registered team receives a unique sequential Team ID (starting from 1)**
- **Automatic group assignment: teams are automatically assigned to one of 18 groups (12 teams per group) in sequential order**
- **ID Pass assignment status tracking: each team registration includes an ID Pass status (assigned/not assigned) that defaults to "not assigned"**
- **Real-time registration counter display showing "X / Y teams registered" format where X is current approved registrations and Y is maximum limit (or "X teams registered" if unlimited)**
- **Production-optimized performance with memory-efficient rendering, optimized React component updates, and reduced re-renders**
- **Memory-efficient data handling with optimized bundle size and tree-shaking for production deployment**
- **Anonymous user registration support - no authentication required for public team registration**
- **Browser-based duplicate prevention using local storage or session tracking for anonymous users**
